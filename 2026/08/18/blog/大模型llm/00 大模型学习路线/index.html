1.基础架构：输入如何进入模型，Transformer 如何处理上下文

  2. 吴恩达机器学习、深度学习课程，配合李沐动手学深度学习教材
  3. cs224n,cs336
  4. bpe学习 实现原始文本 -> tokenizer -> token -> token id -> embedding -> Transformer
  5. transformer，一种是 Encoder–Decoder ，另一种 Decoder-only（现代常用）
  6. attention机制（token之间如何互相读取信息）

3.后训练与对齐：模型如何变得会协作、可控、能推理

  1. SFT：学指令格式、任务接口、基础助手行为
  2. Reward Model、Preference Data：
  3. RLHF：SFT + RM + PPO
  4. Rollout,PPO,GRPO：采样 response，再用 reward / advantage 更新策略
  5. DPO：不显式训练 RM + PPO，直接用偏好对优化
  6. Expert lteration：采样、验证、过滤、再训练
  7. LLM后训练：reward、return、value、advantage、GAE、policy gradient
  8. DAPO：long-CoT、可验证奖励、DAPO recipe、overlong reward shaping
