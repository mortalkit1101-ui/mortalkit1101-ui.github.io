# 修复文章目录重复编号设计

## 问题

文章《从数据生成到模型保存的完整二分类流程》的 Markdown 标题已经包含手写编号，例如 `1.1 数据准备`。Butterfly 主题同时为目录开启了自动编号，因此目录显示成 `1.1. 1.1 数据准备`。

## 目标

- 保留文章标题中的手写编号。
- 目录只显示一套编号。
- 不改变其他文章的目录编号行为。

## 方案

仅在目标文章的 Front Matter 中添加：

```yaml
toc_number: false
```

Butterfly 会为这篇文章关闭目录自动编号，正文标题和目录仍使用文章中已有的 `1`、`1.1`、`1.2` 等编号。全站配置 `_config.butterfly.yml` 保持不变，以便其他文章继续使用主题默认的自动编号。

## 验证

1. 重新生成 Hexo 静态网站。
2. 检查生成的文章目录不再出现 `1.1. 1.1` 等重复编号。
3. 在桌面端和移动端查看文章页，确认目录、正文和页面布局正常。
4. 推送 `source` 并部署 `main` 后，在线检查文章页。

## 范围

只修改目标文章的 Front Matter，并补充相应自动验证；不修改主题目录的全局配置或样式。
