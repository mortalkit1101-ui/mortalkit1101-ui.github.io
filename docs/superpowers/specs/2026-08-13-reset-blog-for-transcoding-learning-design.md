# Blog 内容重置设计

## 目标

清空现有学习笔记及其课程配图，让 Blog 回到可从零开始记录的状态，并将侧栏公告改为“记录从 0 开始的转码学习”。

## 删除范围

- 删除 `source/_posts` 中现有的全部 29 篇 Markdown 笔记。
- 删除 `source/img/courses` 中全部课程配图及封面。
- 删除清空后遗留的空课程目录。

## 保留范围

- 保留 Hexo 与 Butterfly 主题及其配置。
- 保留 `source/img/avatar.JPG`、`source/img/mortal-bg.jpg` 等非课程站点素材。
- 保留关于页、分类页、标签页、域名文件和发布工具。
- 保留历史设计与实施文档，作为仓库变更记录；它们不会发布为博客笔记。

## 文案调整

在 `_config.butterfly.yml` 中将公告卡片内容由“记录电源硬件、数字电源与微波工程学习笔记”改为“记录从 0 开始的转码学习”。

## 验证标准

- `source/_posts` 不再包含 Markdown 笔记。
- `source/img/courses` 不再存在。
- 公告配置只包含新文案。
- Hexo 可以成功生成站点，生成结果不包含旧文章页面。
- Git 变更仅涉及上述删除、公告更新和本设计/实施文档。
