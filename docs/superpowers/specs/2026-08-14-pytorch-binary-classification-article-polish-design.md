# PyTorch 二分类文章轻量润色说明

## 目标

在不改变作者原意、文章结构和学习笔记风格的前提下，提高文章的准确性、可读性与格式一致性。

## 修改范围

- 修正中文错别字及英文 API 名称，例如 `randprem`、`DataLoadar`。
- 调整不通顺或重复的句子，但不扩写为长篇教程。
- 统一 Markdown 标题层级、章节编号、列表和代码块周围的空行。
- 修正少量容易误解的技术表述：
  - `torch.randperm` 返回随机排列的整数索引；
  - `nn.Module` 会注册并管理子模块与可训练参数；
  - `CrossEntropyLoss` 内部组合了 `LogSoftmax` 和 `NLLLoss`，输入应为原始 logits；
  - `model.train()` 和 `model.eval()` 用于切换模型运行模式，本身不会启动训练或验证。
- 将文中的“测试集”统一为“验证集”，与变量 `val_x`、`val_loader` 保持一致。

## 保留内容

- 保留现有标题、Front Matter、示例代码和“重点函数”式讲解。
- 不新增图片、数学推导或额外功能。
- 不重构示例代码的变量命名，以免偏离“简单优化”的范围。

## 验证方式

- 检查 Front Matter 和 Markdown 代码围栏是否完整。
- 检查章节编号是否连续、术语是否统一。
- 运行项目现有的 Hexo 构建命令，确认文章可以正常生成。
